# Cinova App Assets

Place the following files here before submitting to app stores:

| File | Size | Purpose |
|------|------|---------|
| `icon.png` | 1024×1024 | iOS + Android icon |
| `splash.png` | 1284×2778 | Splash screen |
| `adaptive-icon.png` | 1024×1024 | Android adaptive icon foreground |
| `notification-icon.png` | 96×96 | Android notification icon |
| `notification.wav` | — | Custom notification sound |
| `favicon.png` | 48×48 | Web favicon |

## Color Reference
- Background: `#0A0A0F` (deep space black)
- Primary accent: `#6C5CE7` (purple)
- CTA gradient: `#6C5CE7` → `#00CEC9`
